# AI Assistant Guidelines

## Development Approach
- **Strict Scope**: Build exactly what is requested. No unrequested features (e.g., AI chat, complex logging).
- **Single Source of Truth**: Only use Google Sheets. No other database.
- **Design Principles**: Prioritize visual quality (typography, spacing, subtle animations) over component quantity.

## Prompting Guidelines
- When updating UI, ensure Next.js Server Components are favored where possible, passing data to Client Components for interactivity.
- Follow the exact styling instructions: Apple-like, Notion, Linear, Jago aesthetics.
